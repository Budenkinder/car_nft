# Architectural Decision Records

One ADR per request. Filename: `NNNN-<slug>.md` where `NNNN` is a zero-padded sequential number across all ADRs.

Each ADR must be paired with two plan files in `docs/plans/` using the same `NNNN-<slug>`:

- `docs/plans/NNNN-<slug>-frontend.md`
- `docs/plans/NNNN-<slug>-contracts.md`

Use [`_template.md`](_template.md) as the starting point. See repo-root [`CLAUDE.md`](../../CLAUDE.md) for the full workflow.

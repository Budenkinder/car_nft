# In-Progress Plans

Plans here are actively being implemented. Their task checklists are being ticked off as work progresses.

**Entry:** ← `approved/` (or directly from `draft/` if the user said `autonomous` / `implement` without a separate approval step).

**Exit:**
- → `done/` when every task in the plan is complete.
- → `rejected/` if implementation is abandoned mid-way (capture *why* in the decision log).

When a plan moves, both `-frontend.md` and `-contracts.md` move together, and the matching ADR's `Related plans:` paths are rewritten in the same change.

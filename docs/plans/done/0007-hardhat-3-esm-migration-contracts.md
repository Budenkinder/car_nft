## Scope and Goals

Get `npm run compile` and `npm run deploy:*` working again under the already-bumped Hardhat 3 + ESM stack, by replacing the dead `@nomicfoundation/hardhat-toolbox@7.0.0` shim with the correct Hardhat 3 toolbox package and rewriting `hardhat.config.js` and `scripts/deploy.js` against the Hardhat 3 API. No Solidity source changes. No change to deployed contract behavior, ABI shape, or the `deployments/*.json` / `docs/deployments/*.md` output formats.

Out of scope: adding a test suite (none exists today — not introduced by this migration), Hardhat Ignition adoption (the project's script-based deploy flow is kept as-is, just ported to ESM), any Solidity contract change.

- [x] **2.** Rewrite `hardhat.config.js` as ESM:
  ```js
  import "dotenv/config";
  import hardhatToolboxMochaEthersPlugin from "@nomicfoundation/hardhat-toolbox-mocha-ethers";
  import { configVariable, defineConfig } from "hardhat/config";

  const networks = {};
  if (process.env.SEPOLIA_RPC_URL) {
    networks.sepolia = {
      type: "http",
      url: configVariable("SEPOLIA_RPC_URL"),
      accounts: process.env.DEPLOYER_PRIVATE_KEY
        ? [configVariable("DEPLOYER_PRIVATE_KEY")]
        : [],
    };
  }

  export default defineConfig({
    plugins: [hardhatToolboxMochaEthersPlugin],
    solidity: {
      version: "0.8.28",
      settings: {
        // OpenZeppelin v5 emits `mcopy`, which requires Cancun.
        // Sepolia and mainnet both support it.
        evmVersion: "cancun",
        optimizer: { enabled: true, runs: 200 },
      },
    },
    networks,
    verify: {
      etherscan: {
        apiKey: configVariable("ETHERSCAN_API_KEY"),
      },
    },
  });
  ```
  Preserves the existing conditional-Sepolia-network behavior (no dummy RPC URL required for local-only work) and the existing Solidity version/settings. Drops the old top-level `sourcify: { enabled: false }` block — the Hardhat 3 `hardhat-verify` plugin has no automatic post-deploy Sourcify attempt to silence.

## Deployment and Migration

- No on-chain migration — this only changes local tooling (compiler invocation, deploy script, config). No redeploy of already-deployed Sepolia contracts is implied or required by this change.
- Sequence: verify locally (`hardhat node` + `deploy:local`) before trusting `deploy:sepolia` again.
- Verification on Etherscan is now invoked explicitly via `npx hardhat verify --network <net> <address> [constructorArgs...]` (Hardhat 3's `hardhat-verify` plugin) rather than any automatic step — same as before, since the old config never auto-verified either.

## Risks and Rollback

- **Risk:** `@nomicfoundation/hardhat-toolbox-mocha-ethers`'s peer dependency resolution pulls in versions that conflict with other installed packages. Mitigation: `npm install` will surface conflicts explicitly; pin explicit versions if needed.
- **Risk:** `network.create()` behaves subtly differently from the old implicit `hre.ethers` global in edge cases (e.g., signer ordering). Mitigation: task 5's local-node smoke test exercises the full deploy path including signer use and balance reads.
- **Rollback:** `git revert` the commit(s) from this plan; `package.json`/`package-lock.json`, `hardhat.config.js`, and `scripts/deploy.js` all revert together cleanly since they change in lockstep. No on-chain state is touched, so rollback carries no on-chain risk.

# Draft Plans

Plans here have been written but not yet approved by the user. New plan trios start here.

**Entry:** any new `NNNN-<slug>-{frontend,contracts}.md` trio created when an ADR is opened.

**Exit:**
- → `approved/` once the user approves the plan but before implementation starts.
- → `in-progress/` when implementation begins (skipping `approved/` is allowed; just record the transition in the decision log).
- → `rejected/` if the user decides not to adopt the plan.

When a plan moves out of `draft/`, both `-frontend.md` and `-contracts.md` move together, and the matching ADR's `Related plans:` paths are rewritten in the same change.

The plan templates also live here: `_template-frontend.md`, `_template-contracts.md`.
